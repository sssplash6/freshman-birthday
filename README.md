# Freshman Birthday Party — invite site + poster

## Запуск
Откройте `index.html` двойным кликом. Сервер и сборка не нужны.

## Персональное приглашение
Добавьте к ссылке имя гостя:
`https://ваш-сайт/?guest=Aziza`
Имя появится в заголовке («AZIZA, YOU'RE ON THE LIST»), на пропуске, в обращении письма и в блоке RSVP.
Без параметра гость видит «You.» и «Dear friend».

## Что заменить (всё в начале script.js, блок CONFIG)
| Что | Поле | Пример |
|---|---|---|
| Куда отправлять заявки | `submitUrl` | URL веб-приложения Google Apps Script |
| Адрес офиса | `address` | уже вписан: `Nest One, Block C, 15th floor, office 117` |
| Ссылка на карту | `mapsUrl` | сейчас — поиск «NEST ONE Tashkent» в Google Maps; можно заменить точной меткой Google / Yandex / 2GIS |
| Instagram Freshman | `instagram` | `'@freshman.academy'` — появится в призыве «tag us» и на картинке для сторис |
| Длительность события в календаре | `calendarHours` | `3` |

Пока `submitUrl` не заполнен, сайт работает в демо-режиме: бейдж создаётся, но заявка никуда не уходит (в окне это написано).
Пока `address` не заполнен, кнопка карты показывает подсказку.
Если `mapsUrl` пустой, кнопка OPEN IN MAPS откроет поиск Google Maps по адресу.

## Кнопка I'M COMING → салют → форма → именной бейдж
1. Нажатие на I'M COMING (или RSVP внизу) запускает салют в цветах бренда.
2. Открывается форма: ФИО + фото (выбрать файл, перетащить, на телефоне — снять камерой).
3. После отправки гость получает именной пропуск с фото в формате Instagram Stories — PNG 1080×1920,
   с подписью «I'M ON THE LIST.» и призывом выложить его в сторис (с отметкой аккаунта, если задан `instagram`).
   На телефоне главная кнопка — «Share to Stories» (системное меню → Instagram → История),
   на компьютере — «Download for Stories» с подсказкой, как перенести картинку на телефон.
4. Заявка уходит на `submitUrl`. Сайт запоминает гостя: при повторном визите кнопки называются «My pass».

## Список гостей и лимит мест
Список живёт в Google Таблице (лист «Guest list»). Лимит — **70 мест** (`MAX_GUESTS` в `google-apps-script.gs`).

- Бейдж выдаётся **только после того, как таблица подтвердила место**. Каждый гость получает номер (№ 01–70), он стоит на бейдже.
- Когда занято 70 мест: кнопки на сайте меняются на «Guest list is full», форма больше не открывается, новые бейджи не создаются.
  Если список заполнился, пока человек заполнял форму, он увидит «The guest list is full» вместо бейджа.
- Повторная отправка не занимает второе место: если гость меняет имя/фото (то же устройство) или вводит то же ФИО — обновляется его строка.
- Когда останется 10 мест и меньше, на сайте появится «Only N places left» (порог — `spotsHint` в `script.js`).
- **Освободить место:** в колонке «Статус» напишите `cancelled` (или «отменён»). Номера не переиспользуются — следующий гость получит следующий номер.
- Если интернета нет или скрипт недоступен, бейдж не создаётся, гость видит просьбу попробовать ещё раз.

## Подключение Google Таблицы (≈5 минут)
1. Создайте новую Google Таблицу (или откройте ту, что уже подключали).
2. Расширения → Apps Script. Удалите старый код, вставьте содержимое `google-apps-script.gs`, сохраните.
3. **Первый раз:** Начать развертывание → Новое развертывание → «Веб-приложение».
   Запуск от имени: **Я**. Доступ: **Все** (Anyone). Разрешите доступ к Таблице и Drive, скопируйте URL (`…/exec`).
   **Если уже развёртывали раньше:** Начать развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть.
   URL останется прежним, но без этого шага будет работать старый код без лимита.
4. Вставьте URL в `script.js` → `submitUrl`.
5. Проверьте: откройте URL `…/exec` в браузере — должно показать `{"ok":true,"count":0,"limit":70,...}`. Отправьте тестовую заявку — в листе «Guest list» появится строка № 1. После проверки удалите её.

Колонки листа: № · Время · ФИО · Имя из ссылки · Фото (ссылка на Drive) · Статус · ID устройства.
Фото сохраняются в папку «Freshman Birthday Party — фото гостей» на вашем Google Drive.

## Фотографии
Уже стоят три фото (`assets/photos/photo-1.jpg` … `photo-3.jpg`). Чтобы заменить — положите новые файлы с теми же именами.
`photo-3.jpg` показывается широкой рамкой, поэтому для него лучше горизонтальное фото.

## Картинка для превью ссылки
`assets/img/share.jpg` — это постер. Для корректного превью в Telegram/Instagram
после публикации замените в `index.html` путь в `og:image` на полный URL.

## Постер
- `poster/freshman-birthday-poster-1080x1350.png` / `.jpg` — для Instagram (4:5)
- `poster/freshman-birthday-poster-2160x2700.png` — версия 2x для печати/ресайза
- `poster/poster.html` — исходник. Откройте в Chrome, отредактируйте текст, снимите скриншот элемента.
  Постер собран из тех же компонентов и того же `style.css`, что и сайт.
- `poster/freshman-merch-50-off-1080x1350` (.png/.jpg) — пост «−50% на весь мерч, только 1 октября»
- `poster/freshman-merch-50-off-story-1080x1920` (.png/.jpg) — та же акция для Stories
- `poster/merch-sale.html` — исходник акции (`merch-sale.html?story` — версия для Stories).
  Цены взяты с прайс-листа на витрине (фото от 26.09); если цены изменятся, поправьте строки в ценнике.

## Шрифты
Из брендбука: Fixture Condensed — главный заголовок (FRESHMAN / BIRTHDAY / PARTY) на сайте и постере;
Fixture Ultra — только крупные цифры даты/времени и постер акции мерча;
Benzin Bold — все остальные крупные тексты (читаемость), подписи и кнопки; Instrument Serif — письмо; Fixture — мелкий текст.
Подключены локально, подмножество латиницы (~125 КБ).
Fixture распространяется как «Free for Personal Use» — для публичного сайта нужна коммерческая лицензия.
В Fixture и Instrument Serif нет кириллицы; если понадобится русский текст, используйте Benzin или добавьте кириллический шрифт.
